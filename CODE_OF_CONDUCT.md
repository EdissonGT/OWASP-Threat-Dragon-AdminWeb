# Código de conducta / Code of Conduct

Este proyecto adopta el espíritu del [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Se espera trato respetuoso, crítica constructiva y colaboración. No se toleran acoso, discriminación ni ataques personales. El mantenedor puede moderar o eliminar contribuciones que incumplan esto. Para reportar conductas inapropiadas, abre un issue o contacta al mantenedor a través de su perfil de GitHub.
