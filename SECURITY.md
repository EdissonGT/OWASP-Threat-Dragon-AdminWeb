# Política de seguridad / Security Policy

## Alcance

Este repositorio contiene un **modelo de amenazas** (documentación), no código ejecutable. Los datos de infraestructura (IPs, esquemas, tablas, llaves, identificadores) están anonimizados.

## Reportar un problema

- Si encuentras **información sensible real** (credenciales, IPs, nombres internos) que haya quedado en el repositorio, repórtala de forma privada usando *Security → Report a vulnerability* de GitHub (Private vulnerability reporting). No abras un issue público.
- Para errores en el modelo (amenazas faltantes, severidades incorrectas, mitigaciones), abre un issue normal.

Responderé en un plazo razonable e indicaré cuándo se corrige.

## Versiones soportadas

Solo la versión vigente del modelo (`threat-models/AdminWeb/AdminWeb.json`).

If you find real sensitive data in this repository, please report it privately via GitHub's "Report a vulnerability" feature instead of opening a public issue.
